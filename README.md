## Home Lab — SIEM Deployment &amp; Detection Testing

Deployed **Wazuh SIEM** with agents monitoring Windows 11 and Ubuntu 24.04 servers, with File Integrity Monitoring on high-risk directories and tuned scan frequencies.

Then tested what it actually caught, across **15 attack phases mapped to MITRE ATT&amp;CK**, and triaged every resulting alert:

- An SSH brute-force run with Hydra was caught across **all 180 failed attempts**.
- A **Sliver C2 beacon over HTTP produced no alerts at all**. I traced it to log-based detection missing outbound beaconing that generates no failure events, then documented the gap and the controls that would close it.
- Benchmarked both hosts against **CIS standards** (Windows 26%, Ubuntu 47%) and produced a prioritised remediation list.

Full write-up: [redcommand.co.uk](https://redcommand.co.uk/projects/siem-lab-wazuh-deployment-attack-simulation-amp-detection)
